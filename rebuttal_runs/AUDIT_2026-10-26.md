## 1. 结论摘要（按严重度）

### P0：数据规模与划分（会直接改变主结论）

1. **E4 数据集规模：SIDD 已补全，UHDM 已扩到 495/500。**
   - SIDD validation 共 **1,280 块（40 场景×32）**；E4 使用 support 5 块（场景 0–4）、test **1,120 块（场景 5–39×32）**；support 场景剩余 155 块未使用。**原 35 张子集已废弃**，全量与均衡 35 子集结论一致。
   - UHDM 官方 test 共 **500 对**；E4 support 取 **test 的 0–4**；初版 test 取每 9.9 张一张共 **50 对（10%）**，现已扩到 **495/500 对全量**；官方 train 4,500 对未下载、未使用。
   - **子集偏差已量化**：全 500 对 LQ-vs-GT PSNR 均值 **17.117±3.854**；50 对子集 **17.752±3.906**（+0.635 dB，子集略容易）；support 5 对 18.831；剩余 445 对 17.026。即 50 对绝对 PSNR 偏乐观。
   - **已修复（规模）**：已生成 `datasets/E4/uhdm/test_full`（495 对 = 官方 test 500 排除 support 0–4）。全量 495：M_blind **17.307**、官方 DFPIR **15.529**、blinded DFPIR **17.254**、规则 fallback **17.373**；全量 LQ 不恢复 **17.100**。50 子集对应值 17.917/16.230/17.869/18.014，整体高估约 0.61–0.70 dB；按官方 source index 映射后，同一 50 图在两套评估中的数值一致（M_blind 最大差 0），差异来自子集选择。配对 vs M_blind：官方 −1.778 [−1.973,−1.590]（108/495 胜）、blinded −0.053 [−0.081,−0.025]（202/495）、规则 +0.066 [+0.043,+0.090]（282/495）。相对 identity：M_blind +0.208、规则 +0.274；仍无实质 moiré 恢复。

2. **E4 support 划分与任务卡要求不一致。**
   - 任务卡 E4 要求：SIDD 从公开训练部分选 5 对不同原图；UHDM 从官方 train 选 5 对 support，test 用官方独立 test。
   - 实际：SIDD support 来自 **validation 场景 0–4**（不是 train）；UHDM support 来自 **test 的 0000–0004**（不是 train）。
   - support 与 test 图像/场景/索引均不重叠（SIDD 场景 0–4 vs 5–39；UHDM 文件 0–4 vs 5..499，哈希交集 0），因此不是直接测试图泄漏；但不是任务卡要求的 train/test 分离。
   - 未使用 SIDD camera/ISO metadata 分组，也未使用 UHDM 设备/屏幕 metadata；应称为 **dataset-level five-shot stress test**，不能称为条件匹配的场景组。

### P1：协议一致性与解释边界

1. **测试 LQ 协议未固定：7/24 场景跨方法不一致，但实测影响很小。**
   - 7/24 场景（0003、0005、0017、0018、0020、0022、0023）的 `make_lq` 不可复现：`noise_impulse` 调 `skimage.util.random_noise` 未传 RNG；`blur_glass` 调 numba `shuffle_pixels_njit`，使用 numba 私有 RNG。
   - 同一场景同一图两次 `make_lq` 的 LQ-vs-LQ PSNR：impulse **12.23 dB**、glass **33.58 dB**、混合场景 26.98–39.37 dB（`AUDIT_lq_evidence.json`）。现有 AutoIR/规则/DFPIR 三套 test metrics 在这 7 个场景上 **2,450/8,400 行（29.2%）LQ 哈希不一致**。
   - **固定 LQ 重评结果（本次）**：7 个场景物化唯一 LQ 后重评 AutoIR 与规则，逐场景差异 ≤0.02 dB：blind_0005 规则 44.919→44.908、AutoIR 21.916→21.915；blind_0003 规则 27.937→27.939、AutoIR 25.526→25.527；DFPIR-original/best 7 个场景的逐数据集差异 ≤0.012 dB。E1 宏平均不变（rule 24.272/22.132；AutoIR 24.968/22.956），配对 CI 仅移动 <0.02 dB。E2 的 best/last/original 为 25.650/23.616、25.366/23.363、23.995/22.030，相对旧值变化 ≤0.002 dB；best−AutoIR +0.682 [−0.053,+1.451]。**所有结论不变**。
   - **重要更正**：审计脚本初版 `eval_fixed_lq.py` 用 dataset-local `index` 作字典键，DIV2K/LSDIR 的 0–99 冲突，产生过一批无效中间值（如 22.63/24.45）；该文件已改名为 `metrics.invalid_duplicate_index.jsonl`，未进入任何结论。修正后的固定 LQ 结果与旧 metrics 一致。
   - 协议上仍违反 A1“LQ 预生成并固定”；已物化 7 场景固定 LQ（`E1E2_fixed_lq/<scenario>/<dataset>/`），后续评估应复用。E2 的 DFPIR 固定 LQ 重评已完成。

2. **历史 baseline LQ 未跨方法固定。**
   - `scripts/benchmark_inference.py` 只在进程启动时 `np.random.seed(42)`；退化在 DataLoader worker 中生成，随机函数（全部 noise、blur_motion、blur_glass、blur_jitter）的实际 realization 随方法/worker/分片顺序变化。
   - 直接证据：blind_0001 poisson 5，AirNet 与 PromptIR 保存的 degraded 图 PSNR **12.70 dB**；blind_0005 impulse 5 为 12.23 dB；blind_0003 glass 2 为 33.39 dB；确定性 JPEG 1 为 99 dB（仅 JPEG 编码差异）。同图 baseline degraded 与统一评估器 LQ 的 PSNR 也只有 12.23–33.48 dB（JPEG 场景 60.26 dB，为质量 100 编码损失）。
   - **实测模型输出敏感度**：AirNet 在两种 LQ realization 上（50 张中心 512 crop）：blind_0001 mean **+0.0026 dB**、max |Δ| **0.197 dB**；blind_0005 mean **−0.0095 dB**、max |Δ| **0.327 dB**。说明弱 baseline 的输出对 noise realization 也不敏感，历史数值不太可能被 LQ 差异主导。但协议仍不合规，主表应重跑或明确标注“各自 LQ 协议下的参考”。
   - 未修复：本次只重评了 E1/E2 的 7 个非确定场景，没有重跑全部历史 baseline。

3. **E1/E2 的 support 与 DIV2K test 重叠。**
   - exp41 的 5 对 support 全部来自 `DIV2K_valid_HR`；24 场景共 120 次抽取、**74 张唯一图**，每场景 5/100。
   - 证据：`A0/support_test_overlap.json`；本次重新哈希匹配确认 120/120 命中。
   - 影响很小：E1 support-excluded 与全量几乎相同（rule 24.272→24.272；AutoIR 24.9685→24.9686；support+calib-excluded rule 24.283 / AutoIR 24.961）；E2 support-excluded best +0.676 vs AutoIR（全量 +0.683），结论不变。
   - **仍应披露**：主 test 不是严格独立；support-excluded 应作为协议合规版本同时报告。

4. **E4 训练数据来源已核实：不是 SIDD/UHDM 训练集。**
   - 日志：`Train shards: datasets/DIV2K/DIV2K_train_HR_wds/train-*.tar`；`PairedValDataset: 5 image pairs from datasets/E4/{sidd/support, uhdm/support_val}`。
   - `AR_PARAMS_PATH` 为预测管线（skill: `noise_gaussian_YCrCb:1`；规则: `noise_gaussian_YCrCb:5 + contrast:4 + saturation:4`；UHDM 规则 fallback: `compression_jpeg:2`）。
   - 因此：**训练数据 = DIV2K train clean + 预测管线在线合成退化；真实 5 对 support 只用于 quick val / checkpoint 选择；没有用 SIDD/UHDM 训练集，也没有用 support 直接监督训练。**
   - 三个 specialist 均为 0.42M、2 epoch / 15,094 steps、batch16、LR5e-4，训练 1.41 GPU-h/次；SIDD skill/rule 各 1 次 R0，UHDM rule 1 次 R0。
   - **SIDD 新增 X-Restormer 官方单退化高斯去噪基线**：`denoise_300k.pth`（26.04M，σ=50）在 1,120 块上 **32.014 / 0.7197 / 0.4221**，高于 M_blind 30.503、AutoIR 30.533、blinded DFPIR 31.218；比 AutoIR +1.481 dB [CI +0.626,+2.417]。它不是 all-in-one，不能与控制器同类比较，但说明真实 SIDD 上专用去噪器本身很强，AutoIR 没有真实噪声优势。

5. **E2 的 “DFPIR zero-shot” 是项目 blinded，不是官方 5D。**
   - E2 的目的就是“同一 blinded 初始权重 + 相同预算微调”，所以用 blinded 是正确的；官方 5D 是另一个模型，不能与 blinded 混为一行。
   - E4 已改用官方 5D 作为主基线，blinded 仅作项目参考。
   - **必须披露**：blinded 的预训练成本（8-GPU DDP、step301,920、约160 epochs）没有计入 T_s；AutoIR 从头训练。DFPIR-ft 的“同预算”只覆盖微调阶段，不覆盖预训练；报告 T10 目前没有此项成本，标 UNKNOWN。

6. **E4 的规则/skill specialist 只做了单轮 R0，且 quick-val 日志标签是 “Set14”。**
   - `train.py` 在 `AR_CHALLENGE_DIR` 设置时使用 `PairedValDataset`，但打印仍写 `[Ckpt @ step ...] Set14:`；实际评估的是 5 对 support。best_step 选择是 support PSNR。
   - SIDD skill best step 7546、规则 3773；UHDM 规则 11319。三者均在 2 epoch / 15,094 steps 内。
   - UHDM 的 `support_val` 是 support 4K 图的中心 1024×1024 crop（精确中心裁剪）；blind ID/规则使用整张 4K support。报告应写明 selection 用的是 1024 crop。
   - **训练后反思没有发生，且不是 agent 判定“不需要”或运行崩溃**：任务库只有 `E4/*/tasks_*.jsonl` 中的 `*_R0`；没有 R1 任务、R1 params/checkpoint/日志，也没有 `STOP/NO_CHANGE/BEYOND_CAPABILITY` 决策记录。三个 R0 均正常跑到 15,094 steps、无 NaN/异常。训练前 Skill 候选反思确实发生（SIDD `reflection.json` 15 次迭代、最终 UNCERTAIN；UHDM 7 次、最终 POOR/out-of-library），但这不是训练后 R1。按 `CLAUDE.md`，UNCERTAIN/POOR 本应触发 R1；实际是 E4 按任务卡最小真实实验只排了单组 support + 单轮 R0，训练后反思流程未调度。详见 `E4/EXECUTION_NOTE.md`。

### P2：完整性/可追溯性缺口

1. **E1 只报告了 support 选中的 checkpoint，没有 last-round/last-checkpoint test。**
   - 任务卡 E1/A1 要求同时报告 last-round 与 last-checkpoint；当前 `E1/test_metrics` 只有选中轮（R0/R1/R0_fixed）。AutoIR 有 support 选择 vs last-step 的 support 对比（25.06 vs 24.25），但没有独立 test 的 last-step 数字。

2. **T1 未覆盖论文表中的全部 baseline。**
   - `all_methods_comparison.csv` 还包含 N2N、N2N-ft、DIP、MambaIRv2、DATPRL-IR_5task、AgenticIR、JarvisIR、ProWess、IRAgent、FAPE-IR 等列；报告 T1 只逐项说明了 7 个方法 + DFPIR 变体 + AutoIR。
   - AgenticIR 在 CSV 中有数值（DIV2K 20.25、LSDIR 18.56），但没有协议/权重/逐图结果说明。若论文主表出现这些方法，必须补 T1 行；否则应删列。

3. **E4 官方 DFPIR 的 text code 方差已测（SIDD）。**
   - `eval_dfpir_official.py` 支持 `--text-seed`；SIDD 1,120 块上 seed 42/43/44 的 PSNR 为 **23.291 / 23.064 / 23.461**（mean 23.272，range 0.397 dB），三者均低于不恢复 LQ **23.660**。
   - UHDM 只跑了 seed 42（全量 15.529）；结论“低于 M_blind 17.307”在单 code 下成立，UHDM 的 text-code 方差未测。

4. **UHDM 的 tiling 不一致。**
   - M_blind/规则：RestoreNet tile512 + overlap32；blinded DFPIR：tile512 + overlap64；官方 DFPIR：tile1024、无 overlap。
   - 各方法标准推理配置，但会引入 seam 差异；报告需写明。图像全为 4K 3840×2160，未缩放。

5. **已知未执行项**：E6 稳定性、E3-G 留出、E4 rain、E2-RS、E5b、E5c；报告已列限制。Qwen 文档名错误已更正为 `qwen3.7-plus-2026-05-26`。
