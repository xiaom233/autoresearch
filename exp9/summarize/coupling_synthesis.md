# 退化与训练策略的耦合机制 —— 271 组实验的综合理解

## 核心发现

退化和训练策略的耦合发生在**三个独立维度**上，每个维度由不同的退化属性决定。

---

## 一、三维耦合框架

```
退化属性                    训练决策                 效应量级
────────────────────────────────────────────────────
退化在盲预训练中的出现频率  → 是否迁移学习 (Ft/Direct)   0~+5 dB
退化步骤之间的交互强度      → 课程方向 (Fwd/Rev)       0~+4 dB  
退化严重度                  → 调节上述两个效应         从强化到翻转
```

**三个维度是正交的**——知道退化的类型不告诉你怎么课程，知道交互强度不告诉你要不要 Ft。

---

## 二、维度 1：迁移学习由"退化熟悉度"决定

**物理根源**：盲预训练见过的退化模式越多，迁移收益越小。

| 退化在盲预训练中的出现频率 | Ft 优势 | 代表退化 |
|---------------------------|:--:|------|
| 极低（noise-first, 特殊严重度） | **+2.5~+5 dB** | N4 (noise→blur, sev=3), S1 (sev=1) |
| 中等（blur-first, 常规严重度） | +0.3 dB | D1, N1-N3 |
| 高（compression 相关） | ~0 dB | N6-N8 |

**关键反直觉发现**：Ft 优势随严重度升高而**递减**（sev=1: +2.55 → sev=5: -0.03）。不是"退化越重越需要盲预训练"，恰恰相反——退化越轻，盲预训练提供的通用先验越宝贵；退化越重，随机预训练已经见过足够多类似案例，迁移优势消失。

---

## 三、维度 2：课程方向由"退化交互强度"决定

**物理根源**：前一步退化是否会改变后一步退化的统计分布。

### 弱交互（独立退化）→ Rev

```
noise + blur: blur(noise(img)) ≈ blur(clean_img)
→ 噪声被模糊"抹平"，两者独立
→ Rev 剥离外层 blur，再修内层 noise
→ D2: Rev > Fwd +1.95
```

### 强交互（耦合退化）→ Fwd

```
compression + blur: JPEG 块效应被 blur 扩散成新伪影
→ blur(jpeg(img)) ≠ blur(clean_img)
→ 在 clean 图上学的去 blur 无法迁移到 jpeg+blur 图
→ 必须 Fwd：先学去 JPEG（易）→ 在此基础上叠加去 blur
→ D3: Fwd > Rev +4.27
```

**判断交互强度的标准**：问自己"在 clean 图上学会的技能，能直接用于 degraded 图吗？"不能→强交互→Fwd。

---

## 四、维度 3：严重度调节上述两个效应

### 对迁移学习（Ft vs Direct）的调节

```
sev=1: Ft +2.55  (退化极轻，盲预训练先验极宝贵)
sev=3: Ft +0.04  (接近平衡)
sev=5: Ft -0.03  (退化极重，随机预训练已覆盖)
```

单调递减。**Ft 是轻退化的最优策略，重退化时 Direct 即可。**

### 对课程方向的调节

| blur | sev=3 | sev=5 | 严重度效应 |
|------|:--:|:--:|------|
| motion | Fwd | Rev | **翻转** |
| lens | Rev | Rev | 保持并增强 |

不对称。motion 在极端严重度下课程方向翻转，lens 保持。

### 不平衡严重度

当退化步骤的严重度不均衡（如 blur(5)+noise(1)）：

- **外层退化（noise/compression）严重**：推往 Rev——需先剥离严重的外层
- **内层退化（blur）严重**：效果不对称——motion 强化 Fwd（需先修复严重的内层），lens 反而取消 Rev

---

## 五、三维决策的交互

**三维是正交的，决策时需分别判断：**

```
1. 先判断 Ft vs Direct：退化"常见"吗？
   → sev≤2 几乎总是 Ft 对
   → 不确定时永远先跑 Ft（30+ 组中从未显著输）

2. 再判断 Fwd vs Rev：退化步骤交互强吗？
   → 噪声+模糊 → Rev
   → 压缩+模糊 → Fwd（正序）
   → 三退化中 blur=motion → Fwd, blur=lens → Rev

3. 严重度作为调节：
   → sev≥5 时 motion→Fwd 不再适用（翻转）
   → 不平衡时严重步骤主导方向
```

---

## 六、什么不重要

经过 271 组实验检验，以下因素对结果影响始终 < 0.3 dB：

- Loss 函数选择（l1/mse/huber/l1+edge/l1+fft）
- Fine-tune 阶段 2 的微调方式（LR、冻结、回放）
- 多专家架构（从未超越单模型 Ft）

---

## 七、用一张表总结

| 退化特征 | 推荐策略 | 原因 |
|----------|----------|------|
| 任意退化, sev≤2 | **Ft** | 盲预训练优势最大 |
| noise+blur (任意顺序) | **Ft + Curric(rev)** | 弱交互, 外层剥离 |
| comp+blur (comp 先) | **Curric(fwd)** | 强交互, 正序渐进 |
| comp 在外层 + X | **Curric(rev)** | 外层先剥离 |
| 三退化, blur=motion | **Ft + Curric(fwd)** | 线性拖影, 单独可逆 |
| 三退化, blur=lens | **Ft + Curric(rev)** | 复杂 PSF, 先 JPEG |
| 三退化, 其他 blur | **Ft** 或 **MW** | 无方向偏好 |
| 不确定 | **Ft** | 永远不会显著差 |
