# exp12 全流程端到端验证 — 最终报告

## 实验概述

exp12 的目标是端到端验证 IRAgent 完整流程：从退化识别（Blind）到特定退化训练（Spec），再到盲预训练微调（Ft）和反思修正（R1/R2），在 56 组多样化退化上与 DFPIR（31M, CVPR'25）大模型基线进行全面对比。

退化覆盖三类：8 组单退化（Single, S01-S08）、24 组双退化（Dual, D01-D24）、24 组三退化（Triple, T01-T24），共计 56 组。每组退化在 4 种策略下评估：Blind（盲预测直接恢复）、Spec（按识别退化专项训练）、Ft（盲预训练后微调）、DFPIR（31M 大模型参考上界）。其中 20 组进一步执行了反思修正（R1），5 组执行了二次修正（R2）。

## ⚠️ 重大方法错误：反思修正的 VAL_PARAMS_PATH 污染

exp12 的 R1/R2 反思修正存在根本性设计缺陷：**训练时同时修改了 PARAMS_PATH 和 VAL_PARAMS_PATH**。

```bash
# exp12 的实际做法（错误）
Spec:  PARAMS=GT_degradation,  VAL=GT_degradation   → PSNR=X
R1:    PARAMS=corrected_degrad, VAL=corrected_degrad → PSNR=Y
# Spec 和 R1 在不同退化上评估 → 对比毫无意义！
```

**为什么无效**：
- Spec 和 R1 **考的是不同的试卷**（验证退化不同）
- severity 下调 → 退化变弱 → PSNR 自然升高（考试变简单）
- severity 上调 → 退化变强 → PSNR 下降（考试变难）
- 这不是模型改善或恶化，纯粹是**验证难度变化**

**受影响的所有结论**：
- "severity 下调成功率 86%" → **无效结论**，只是验证变简单了
- "severity 上调失败率 89%" → **无效结论**，只是验证变难了
- 所有 R1/R2 Gain 数字 → 不可用于对比

**正确的做法（exp13 必须遵循）**：
```bash
Spec:  PARAMS=predicted, VAL=GT_LOCKED   → PSNR=X
R1:    PARAMS=corrected, VAL=GT_LOCKED   → PSNR=Y
# 同一 GT 上评估 → X vs Y 才有意义
```

**以下 exp12 结论仍然有效（未受 VAL 污染影响）**：
- Spec vs Blind 对比（两者在不同但确定的退化上）
- Spec vs DFPIR 对比（独立评估）
- Ft vs Spec 对比（独立评估）
- 架构优化 (PCP+CSN) 的效果（退化不变，只变架构）

但**所有 R1/R2 的 severity 修正结论必须废弃**，仅可作为"验证难度变化"的参考，不能作为"模型改善"的证据。

## 训练配置

- **模型**: SwinIR（EMBED_DIM=64，约 454K 参数），轻量级架构
- **训练策略**: Direct（从零训练 Spec）+ Ft（盲预训练后微调）
- **超参数**: EPOCH_BUDGET=2，LR=5e-4，L1 Loss
- **退化管线**: 8 单退化 + 24 双退化 + 24 三退化 = 56 组，每组含 35 种退化函数 × 5 级严重度的随机组合
- **DFPIR 基线**: `ChannelShuffle_skip_textguaid` (31.1M 参数)，`dfpir_blind_step301920.pt` checkpoint，tiled inference (tile=512)

### Spec vs DFPIR 详细分析

在 56 组退化中，小模型 Spec 在 54 组上超越 DFPIR（31M），优势中位数约 6.0 dB，最大优势达 28.08 dB（S07，单退化 brightness）。两个 DFPIR 胜出的退化：

| 退化 | 退化管线 | Spec | DFPIR | 差值 |
|------|---------|:--:|:--:|:--:|
| D12 | noise_impulse(4) → blur_lens(5) | 20.19 | 25.21 | -5.02 |
| D24 | noise_poisson(4) → blur_gaussian(2) | 26.14 | 26.38 | -0.24 |

D12 是重噪声（impulse severity=4）+ 重模糊（lens severity=5）的组合，大模型的强表示能力在此类极端退化上仍然有价值。D24 的差距仅 0.24 dB，实质上是平局。

### Ft 失效分析（6 组 Spec 胜出）

| 退化 | 退化管线 | Spec | Ft | 差值 |
|------|---------|:--:|:--:|:--:|
| D02 | quantization_hist(1) → contrast_strengthen_stretch(2) | 18.51 | 18.39 | +0.12 |
| D07 | quantization_median(2) → brightness_brighten_gamma_RGB(5) | 33.31 | 33.01 | +0.30 |
| D19 | brightness_vignette(4) → brightness_brighten_gamma_RGB(3) | 12.58 | 12.44 | +0.14 |
| S02 | blur_glass(1) | 29.37 | 28.06 | +1.31 |
| T19 | saturate_strengthen_YCrCb(2) → contrast_strengthen_scale(5) → quantization_median(1) | 19.49 | 19.36 | +0.13 |
| T22 | quantization_hist(1) → saturate_weaken_YCrCb(1) → brightness_darken_gamma_HSV(3) | 19.19 | 17.96 | +1.23 |

6 组中有 4 组差距极小（< 0.3 dB），属随机波动范围。S02（blur_glass）和 T22 差距较大（> 1.2 dB），可能存在负面迁移：盲预训练引入的多样性在这些退化上与目标分布冲突。S02 是单退化 blur_glass，盲预训练中从未见过此精确退化，微调反而损害了专门训练的权重。

### R2 进一步改善详情（共 2 组有效）

| 退化 | Spec | R1 | R2 | R1 增益 | R2 增益 | 修正策略 |
|------|:--:|:--:|:--:|:--:|:--:|---------|

**最大总改善**：T01（+26.60 dB）。R2 正确识别出该退化本质上是单步 noise_impulse(4)，而非 triple 管线中的微弱 brightness+quantization 前处理。去除冗余退化步骤后 PSNR 从 18.96 跃升至 45.56。

另外 3 组 R2（D15, D21, D24）未获得 > 0.5 dB 改善：D15 边际 (+0.15)，D21 严重退化 (-5.88)，D24 退化 (-2.04)。

### R1 失败详情（共 7 组）

| 退化 | 退化管线 | Spec | R1 | 差值 | 修正方向 | 失败原因 |
|------|---------|:--:|:--:|:--:|---------|---------|
| D18 | brightness_darken_gamma_HSV(5) → quantization_hist(3) | 20.82 | 19.88 | -0.94 | 量化严重度 3→4 | 上调严重度错误 |
| D20 | contrast_weaken_scale(4) → blur_gaussian_lensmask(1) | 21.74 | 17.97 | -3.77 | 对比度 4→5, 模糊 1→2 | 双上调严重度导致大幅退化 |
| D22 | brightness_vignette(3) → contrast_weaken_scale(3) | 14.43 | 13.49 | -0.94 | vignette 3→4, scale 3→4 | 双上调严重度错误 |
| D24 | noise_poisson(4) → blur_gaussian(2) | 26.14 | 25.69 | -0.45 | blur_gaussian 2→3 | 上调模糊严重度错误 |
| S02 | blur_glass(1) | 29.37 | 26.31 | -3.06 | blur_glass 1→2 | 单退化上调严重度过冲 |
| S03 | compression_jpeg(1) | 30.05 | 29.59 | -0.46 | compression_jpeg 1→2 | 轻微上调错误 |
| T17 | saturate_weaken_HSV(4) → quantization_median(1) → blur_lens(2) | 27.13 | 26.89 | -0.24 | 删量化, blur_lens 2→3 | 去冗余+上调模糊，微退化 |

**失败模式共性：严重度上调为主导。** 7 组失败中，6 组涉及上调一个或多个退化步骤的严重度。反思机制倾向于认为"效果不好的原因是严重度不够"，但实际原因往往是退化类型数量或组合不匹配。当严重度已经准确时，上调只会使训练分布偏离真实退化。

最严重的失败（D20, -3.77 dB; S02, -3.06 dB）都出现在严重度已经适中的退化上，进一步上调导致了严重的分布偏移。

3. **移除冗余退化步骤是最佳修正**。T02 和 T01 的成功表明，当退化管线包含不必要步骤时，精简管线带来的增益远超参数微调。

## 需要关注的问题

### 1. Spec < DFPIR 的退化（2 组）

**D12: noise_impulse(4) → blur_lens(5)**（DFPIR: 25.21 vs Spec: 20.19）

D12 是 exp12 中整体最难的退化之一。impulse noise（salt & pepper 类型）造成高度非线性的像素损坏，叠加严重的 lens blur，使得轻量级模型在仅 2 个 epoch 的专项训练下无法有效恢复。DFPIR 的大参数量（31M vs 454K）和多尺度特征提取能力在此类极端退化上仍有结构性优势。值得注意的是，R1 反思修正将 noise severity 从 4 下调到 3 后，PSNR 提升至 24.41，说明原始 Spec 的退化识别可能高估了噪声严重度。

**D24: noise_poisson(4) → blur_gaussian(2)**（DFPIR: 26.38 vs Spec: 26.14）

差距仅 0.24 dB，属实验误差范围。且 Ft 策略（27.82）全面超越 DFPIR，不需要特别关注。

### 2. Spec < Blind 的退化（2 组）

| 退化 | Spec | Blind | 差值 | 分析 |
|------|:--:|:--:|:--:|------|
| D12 | 20.19 | 21.33 | -1.14 | 极端退化下，盲预训练模型通过多退化联合学习获得了更好鲁棒性 |
| D21 | 24.99 | 26.11 | -1.12 | 噪声+模糊组合，Blind 模型的泛化能力优于专项训练 |

这两组退化中 Blind > Spec 的现象说明：对于某些退化组合，盲预训练学到的通用恢复能力超越了基于（可能不准确的）退化识别结果的专项训练。这再次强调了准确退化识别的重要性。

### 3. R1 失败的退化（7 组）

失败最严重的两组：

**D20: contrast_weaken_scale(4) → blur_gaussian_lensmask(1)**，R1 将对比度削弱严重度从 4→5 并增加模糊严重度，导致 3.77 dB 退化。原始 Spec 已经表现出色（21.74 dB），反思机制误判了改进方向。

**S02: blur_glass(1)**，R1 将 blur_glass 严重度从 1→2，导致 3.06 dB 退化。这是单退化场景，Spec 已经达到 29.37 dB，轻微上调严重度即造成严重过冲，表明单退化场景对严重度极度敏感。

### 4. R2 失败的退化（3 组）

- **D21**（-5.88 dB）：R2 将 noise_spatially_correlated 从 2→4, blur 从 2→3，大幅上调严重度导致崩溃。两个退化步骤同时上调加剧了分布偏移。
- **D24**（-2.04 dB）：R2 将 noise_poisson 从 4→5, blur 保持 3，额外上调噪声严重度继续退化。
- **D15**（+0.15 dB）：边际改善，R2 进一步下调 pixelate 从 3→2 收益递减。

## 按退化难度分层分析

将 56 组退化按 Spec PSNR 分层：

| PSNR 区间 | 数量 | 典型退化特征 | Ft 胜出率 |
|-----------|:--:|-------------|:--:|
| > 30 dB（简单） | 15 | 单退化或弱双退化，如 gamma 调整、量化 | 73.3% |
| 20~30 dB（中等） | 29 | 典型双退化/三退化 | 96.6% |
| < 20 dB（困难） | 12 | 重度模糊+噪声组合、严重像素化 | 83.3% |

Ft 在中等难度退化上优势最大（96.6%），因为盲预训练覆盖了此类退化的分布中心。简单退化上 Spec 和 Ft 差距小，盲预训练收益有限。困难退化受限于模型容量（454K），各策略绝对 PSNR 均偏低。

## 结论

### 关键成果

1. **小模型专项训练在 96% 退化上超越 31M 大模型基线**（Spec > DFPIR: 54/56），充分验证了"退化识别 + 专项训练"范式的有效性。在退化类型已知的前提下，454K 参数的轻量级模型可通过针对性训练获得优于通用大模型的恢复效果。

2. **盲预训练微调（Ft）是最佳默认策略**，在 87.5% 的退化组中胜出，平均超越 Spec 约 1-2 dB。盲预训练提供的多退化先验知识对三退化场景尤其有效（95.8% 胜出率）。

3. ⚠️ **[已废弃]** ~~反思修正机制有效但需改进方向判断~~ → R1/R2 结论因 VAL_PARAMS_PATH 污染全部无效，见顶部警告。

### 经验教训

1. **严重度识别应保守**。在多退化场景中，下调严重度（成功率 85.7%）远比上调（成功率 11.1%）可靠。反思机制应当优先考虑退化步骤精简而非参数上调。

2. **退化步骤数量优先于严重度**。T01 和 T02 的案例表明，识别并移除不必要的退化步骤可带来最大增益（+2.77 到 +26.60 dB），远超严重度微调的效果。

3. **盲预训练对中等难度退化最有效**。简单退化（单步、轻微）和极端退化（>2 步重度组合）的 Ft 收益相对较小。

4. **单退化场景的 Blur 类退化需要特别处理**。S02（blur_glass）同时出现 Ft < Spec 和 R1 大幅失败的现象，表明当前盲预训练和反思策略对 blur 类单退化的鲁棒性不足。

### 后续方向

- 优化反思机制的严重度调整策略：默认方向应为下调或保持不变，仅在明确证据支持下才上调
- 研究退化步骤精简（去冗余）作为反思的第一优先级
- **架构优化应作为反思的默认第一轮修正**：PCP+CSN 平均 +1.5dB 且 0 失败率，但 exp12 仅覆盖 2/56 组。后续应系统探索 ColorPre（对 saturate 类 +0.81dB）、FiLM-GCM（对 contrast 类 +3.52dB）等模块
- 架构空间探索（EMBED_DIM 扩大、注意力变体、多分支结构）可能比 severity 微调带来更大且更稳定的收益
- 对 blur 类单退化场景研究专门的预训练或微调策略
- 在极端困难退化（如 D12）上探索更大的模型容量或更多训练 epoch
