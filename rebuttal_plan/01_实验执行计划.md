## 2. 所有新增实验共用协议（A1；P0）

1. 冻结代码、工具、阈值、规则、提示词、数据清单及哈希；为每场景建立 support/selection/test 三份列表。最低方案使用 5 对 support 作决策与选择，承认选择可能过拟合；最终 test 必须内容独立。若另有 selection 配对数据，所有对照等量获得，并明确已超出“仅五对”条件。
2. 外部训练 clean 图与 support/selection/test 按原图 ID、来源和内容哈希核查；裁剪来自同一原图也算同一图。噪声 LQ 预生成并固定，所有方法使用同一测试 realization。
3. 决策容器只见 support、工具、预测和脱敏训练诊断。评估器另持隐藏参数与 test；最终一次性评估后不得据此选 round/模型/规则。最终 GT test 分数不得用于 CLR 触发或停止。
4. 统一 RGB [0,1]、裁边、尺寸、padding、颜色空间、SSIM 核与聚合、LPIPS VGG/Alex 与 [-1,1] 归一化。历史 SSIM 先以少量同预测图比较训练实现和离线实现，再对所有方法统一重算。逐图 PSNR 求均值与先求 MSE 再转 dB 不混用。
5. 选择策略预注册：支持验证 PSNR 择优 checkpoint/round；NaN 检测使用训练状态；回退策略对所有控制器相同。另报 last-round 和 last-checkpoint，展示选择影响。
6. 第一批统一初始化、数据、batch、裁剪、优化步数和最大候选训练数。EPOCH=2 是历史候选值，需 A0 确认；不同 crop/batch 不可只比 epoch。实际 GPU-h 单独记录，不能认为同步数等于同算力。
7. 模型种子初次固定42；多种子实验先实现 AR_SEED，覆盖 torch、CUDA、Python、NumPy、DataLoader workers 和数据合成。远端 API 无法保证种子时记录重复 run ID 与采样参数。

需新增的最小实现：显式 checkpoint 评估器（逐图三指标+预测哈希）；五对支持样本清单读取器（先验证现有 PairedValDataset 目录规则）；统一决策可见数据导出器；种子接口；控制器调用/成本记录器；基于成功标志的无全局 kill 启动器。没有这些功能前，不声称下列任务已可一键跑。

单候选训练环境的已核验字段：AR_PARAMS_PATH=估计管线，AR_CHALLENGE_DIR=配对支持目录，AR_EPOCH_BUDGET=审计后确认值，AR_LEARNING_RATE=审计后确认值，AR_BATCH_SIZE=16（候选值），AR_TRAIN_CROP=审计后确认值，AR_LOSS_FN=l1，AR_CKPT_PREFIX=独立新run目录，AR_ATTENTION_TYPE=swin/mdta/ocab，AR_USE_GCM/AR_USE_DUAL_BRANCH 等。AR_LOAD_CKPT=已核验的预训练权重仅用于Ft；Direct不设置。不要加不存在的AR_SEED后假定已生效。

新实验建议目录：rebuttal_runs/<experiment_id>/<scenario_id>/<controller>/<support_id>/<agent_run>/；其下保存manifest、decision_trace.jsonl、完整配置、脱敏日志、checkpoint清单、support选择记录、逐图test指标、完成标志。不可覆盖expN旧文件。

决策流程仍执行项目规定的盲识别/反思隔离协议；本任务仅制定计划，未启动这些阶段，也未创建子智能体。规则控制器是明确标记的对照实验，其结果不得冒充按项目协议产生的LLM盲识别结果。
