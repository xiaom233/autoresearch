**T2 配对结果（rule − AutoIR，按场景 bootstrap）**：DIV2K **−0.697 dB**，95% CI [−3.409,+2.246]，规则胜 **8/24**；LSDIR **−0.825 dB**，CI [−3.391,+1.768]，规则胜 **8/24**。平均差不为正且 CI 跨 0 → **LLM 相对冻结规则没有统计显著的独立优势**。极值很大：规则在 blind_0005 +23.0（AutoIR 21.92 → 规则 44.92）、0009 +6.5、0001 +4.6；AutoIR 在 0008 +20.5（规则 22.65 → AutoIR 43.18）、0010 +10.6、0024 +4.3。说明两者是互补而非单向优越；规则若见过类似场景也可能极强，LLM 的优势是场景相关的。

**support 排除稳健性**：DIV2K support-excluded，rule 24.272 vs AutoIR 24.969（Δ−0.697）；support+calibration-excluded，rule 24.283 vs AutoIR 24.961（Δ−0.678）。结论不变。

**规则独立性限制**：`finetune_strategy.md` 明确引用 exp40 的 blind_0007/0018/0020/0024 修复案例（best ckpt、NaN 回退等），规则控制器的架构/回退知识并非对这 24 个场景完全无知。因此 E1 只能支持“同一工具与规则知识下，LLM 相对冻结规则的增量贡献”，不能支持“规则是未见场景的独立基线”或“规则/LLM 可泛化到新场景”。

### blind_0018 案例：规则触发 vs LLM 决策

**事实**：exp41 blind_0018 的 R0/R1/R2 预测管线保持不变（`contrast_strengthen_stretch:4 + compression_jpeg:5`）；R0 无 GCM，R1 使用 Swin+SimpleGate+GCM。GT 重评估 DIV2K 从 R0 **17.46** 升到 R1 **19.56**（**+2.10 dB**；LSDIR 17.31→18.89，+1.58 dB）。R2 **实际未启用 GCM**（`training_strategy.json` 写了错误的 `AR_USE_FILM_GCM=1`，train.py 只识别 `AR_USE_GCM`），回到 17.53/17.40；R3 修复为 `AR_USE_GCM=1` 后为 19.05/18.53（相对 R2 +1.52/+1.13）。R2 不是主动判定“GCM 无益”，而是环境变量配置 bug。

**因此**：这 +2.1 dB 是 **RS 配置有效性的证据**，不是“LLM 独立发现了一个新架构”；R2 的下降也不是“GCM 无效”，而是配置 bug。GCM 的启用条件明确来自 `finetune_strategy.md` Section 七：contrast + 结构化局部退化（JPEG/blur）+ `variance_ratio` 偏离 1；`training_strategy.json` 还记录 `source: finetune_strategy.md Section 七 信号门控规则`。如果把 GCM 算作 LLM 的独立设计，会重复计算规则知识。

**这个案例中真正由 LLM/Agent 做、且可在 reflection 轨迹里追溯的决策**：

| 决策 | 证据（reflection/iteration） | 性质 |
|---|---|---|
| 初判 contrast + JPEG；初始猜 `contrast_strengthen_scale` + `saturate_strengthen_HSV` | iterations 3–5：PSNR 16.40/19.77/16.52，CI 4/4/3，均 REJECT | 假设生成/否定 |
| 改用 `contrast_strengthen_stretch:4` 子类型 | iterations 12/14/18：stretch 候选；最终 29.42 dB、CI 10/10；reflection key_finding 明确 “scale 失败，stretch 才是正确类型” | **DC 子类型重释**（不是 RS） |
| 删除 saturation 假阳性 | `saturation_chroma_ratio=1.588` 被归因于 contrast stretch；加 saturation 候选 12.47 dB，REJECT | 信号假阳性剔除 |
| 删除 noise | `sigma=0.86 < 2` + Qwen NO；noise 候选 10.46/12.38 dB，REJECT | 信号假阳性剔除 |
| 反向顺序测试 | R1：JPEG→contrast，PSNR 20.26、CI 2/10，REJECT；原顺序 CI 10/10 | **顺序/CLR 证据** |
| 拒绝 impulse | R2 peeled residual `extreme_pct=90.57%` → impulse；impulse 1/3/5 分别 27.63/23.94/21.03，全部低于 29.42，判定为 contrast+JPEG 边缘残差的假阳性 | **残差信号重释** |

| 停止/保持 | R4 测 10 个候选（JPEG 1–4、contrast 3/5、saturation、gamma、brightness、weaken）均更差，KEEP | CLR 终止判断 |

数值来源：`exp41/results/gt_reeval_R0.json`、`gt_reeval_R1.json`、`gt_reeval_R2.json`、`gt_reeval_R3.json`；训练/选择日志：`exp41/logs/exp41_R{0,1,2,3}_blind_0018.log`。

**结论表述**：blind_0018 可以支持“规则规定的 GCM 配置在该固定退化上有效（+2.1 dB）”；可以支持“Agent 在 DC 侧通过 subtype/severity/顺序/残差信号重释修正并确认了管线”；**不能**支持“GCM 是 LLM 独立发现的架构”或“这 2.1 dB 来自独特 agent reasoning”。论文/回应应把该案例放在 RS 配置有效性，而不是 LLM 独立贡献的主证据。

### blind_0003 案例：LLM 的 DC 假设扩展，但最终切换用了 GT 反馈

> 详细逐轮档案（原始 JSON/日志、35 条 reflection iteration、规则条款和 E1 规则控制器对比）：`rebuttal_plan/case_blind_0003/report.md`。

**事实/逐轮结果**：

| 轮次 | 预测管线 | 架构 | DIV2K PSNR | LSDIR PSNR |
|---|---|---|---:|---:|
| R0 | `blur_gaussian:2` | Swin | 23.50 | 20.63 |
| R1 | `blur_gaussian:2` | Swin+SG | **25.50** | **22.31** |
| R2 | `blur_gaussian:2` | Swin+SG | 21.75 | 18.87 |
| R3 | `blur_glass:2` | Swin+SG | **27.20** | **23.52** |
| R4 | `blur_glass:2 + blur_gaussian:1` | Swin+SG | 27.03 | 23.40 |

**规则规定的部分**：
- blur 为 Tier B → 纯 Swin / Direct；无 motion → 不用 OCAB；SimpleGate 默认开启（R0→R1 的 +2.00/+1.68 dB 属于这个默认架构升级，不是 LLM 的新设计）。
- `REFLECTION_MECHANISM.md` 规定“PSNR 改善 ≠ blur 子类型正确”；因此 R1 即使发现 glass:2 的仿真 PSNR 更高，也不能仅凭 PSNR 改主预测。

**LLM/Agent 实际做出的部分**：
- R0 只测了 gaussian；R1 **主动测试了此前未测的 glass:2**，得到 PSNR 36.65、CI 10/10，而 gaussian:2 为 34.83、CI 8/10；这是 LLM 的**候选扩展**，不是规则直接给出的子类型。
- R1 识别 `dct_zero_ratio=0.624` 是 blur 造成的 JPEG 假阳性（添加 JPEG 使 PSNR 降到 29.76–32.04），并排除 noise（sigma=1.11<2；peeled residual 是 blur 残差）。
- R1 在“更高 PSNR 的 glass”与“保守保持 gaussian”之间选择保持 gaussian；R2 继续 gaussian。这里体现了对 REFLECTION 规则的遵守，也暴露了 support-only 选择过于保守。
- R3 最终切到 glass:2，DIV2K 从 R2 的 21.75 升到 **27.20**（+5.45），相对 R0 +3.70；但 R3 的触发依据明确写了 **“GT training PSNR=19.33 证明 gaussian:2 错误”**，属于 **GT/test 反馈（hindsight/oracle）**，不是纯 support 选择。

**结论**：
- blind_0003 **确实比 blind_0018 更能说明 LLM 在 DC 侧的作用**：它扩展了 blur 子类型候选（glass），并在 support 信号上找到了比 gaussian 更好的 CI/PSNR 证据；同时正确排除了 JPEG/noise 假阳性。
- 但它**不能**证明“LLM 仅凭 support 就独立选中了正确子类型”：R1 已经找到 glass 却没有选，R3 的正确切换依赖 GT 训练 PSNR。因此这个案例应标为 **LLM 生成候选 + 规则/协议约束下的保守选择 + GT 反馈后的修正**，不能包装成完全无 test 反馈的独立发现。
- 架构侧仍然只有规则：R0→R1 的 +2.0 dB 是 SimpleGate 默认升级；R3 的大幅提升来自 **DC 子类型切换**，不是 LLM 发现新网络。

**详细档案与 checkpoint 口径**：逐轮原始数据、35 条 reflection iteration、规则条款引用和 E1 规则控制器对比见 `rebuttal_plan/case_blind_0003/report.md`。补充两点：(1) 上表 21.75→27.20 是 step7546 口径；按数值最后一步 step15092 口径，R2=25.33、R3=26.25（+0.92），737 张 GT 门控是 R2=19.33→R3=24.33（+5.00）。轮次级 dB 对 checkpoint 选择敏感，不能把 +5.45 当作稳定增益。(2) E1 规则控制器在同一场景 R1 直接选 glass:2，固定 LQ 27.94/24.19，优于 AutoIR 的 R1 gaussian 25.53/22.33；因此本案例不能用来论证 LLM 优于规则，只能论证 LLM 的候选空间扩展和规则过度保守。

### T5e RS 规则来源与 24 GT 场景独立性（本次审计）

详见 `RS_rule_provenance_audit.md`。结论分两层：

**GT 侧（不完全是“未经校准”）**
- 校准脚本（blur 2026-06-20、JPEG 2026-06-21）**早于** exp40 的 24 个 challenge（2026-06-30）；GT 由 `blind_challenge.py` 随机生成，没有按模型表现挑选的记录；但生成 seed/命令未保存。
- **3/24 的 GT 链恰好也是校准配置集成员**：`blind_0006` JPEG:1、`blind_0011` poisson:3+gaussian:4、`blind_0013` speckle:3+JPEG:2；另有 0801–0810（10/100 DIV2K test 图）参与 JPEG 校准；3840 批次 manifest 未追回。因此**不能声称 24 个 GT 与校准完全独立**；这 3 条对识别工具不算严格 held-out。

**最终结论（SIDD + UHDM + Rain）**：
- **SIDD 真实噪声（1,120 块全量）**：无恢复 LQ 为 **23.660 dB**。M_blind **30.503**、AutoIR/Skill **30.533**（+0.030，95% CI [−0.691,+0.715]，22/35 胜）、规则 specialist **21.625**（−8.878 vs M_blind，0/35 胜，**比不恢复还低 2.03 dB**）、DFPIR official release 5D **26.465**（−4.038 vs M_blind，2/35 胜）、DFPIR blinded 项目参考 **31.218**（+0.715，CI [−0.544,+2.006]，18/35 胜）、X-Restormer 单退化高斯去噪 **32.014**（+1.511，CI [+0.270,+2.861]，17/35 胜）。均衡 35 子集与全量结论一致（见上表），说明原 35 图结果不是挑选偏差。
- **SIDD 的关键否定结果**：(a) **官方 5D DFPIR 不迁移到真实 sRGB 噪声**（正确 CLIP prompt 下 26.465，高于不恢复 23.660，但仍比 M_blind 低 4.038；其训练任务为合成 5D 退化，SIDD 是分布外）；(b) **AutoIR 相对 M_blind 无统计显著提升**（+0.030 dB，CI 跨 0）；(c) **规则控制器在真实噪声上灾难性失败**（−8.878 dB vs M_blind，且 2/35 才胜过 AutoIR），根因是把噪声伪信号当作 contrast/saturation 并过度预测 severity；(d) blinded DFPIR 31.218 不显著，X-Restormer 单退化高斯去噪以 **32.014** 成为最高 PSNR（比 AutoIR +1.481 dB，CI [+0.626,+2.417]），说明真实 SIDD 上专用去噪器本身就很强；AutoIR 不仅未超 M_blind，也低于该单退化去噪器。因此 E4 **不支持**“在真实 SIDD 上显著提升恢复质量”的强结论；它能支持的是“系统可运行、AutoIR 能避免规则式主动伤害、并在库外数据上保守拒绝”。 补充：**所有 official 4D/5D/all-in-one 基线都低于 M_blind**；其中 DFPIR official release 5D（CLIP σ=25）26.465 最高，仍比 M_blind 低 4.038；PromptIR 24.462、AirNet 23.891、DCPT-5D 23.156、R2R-5D 22.530、DATPRL-5Task 15.673、DATPRL-CDD11 13.182。只有单退化 X-Restormer 32.014 高于 M_blind。
- **UHDM 真实 moiré（495 对全量）**：库内无算子；AutoIR/Skill 输出空 pipeline + POOR（out-of-library 高置信），规则控制器无共识并 fallback 到 JPEG:2。不恢复 LQ 为 **17.100 dB**；M_blind **17.307 / 0.6387 / 0.5020**；DFPIR 官方 5D **15.529 / 0.4716 / 0.5889**（−1.778 [−1.973,−1.590] vs M_blind，108/495 胜）；DFPIR blinded 参考 **17.254 / 0.5847 / 0.5234**（−0.053 [−0.081,−0.025]，202/495）；规则 fallback **17.373 / 0.6236 / 0.5068**（+0.066 [+0.043,+0.090] vs M_blind，282/495，但 SSIM/LPIPS 更差）。所有方法相对不恢复的 PSNR 提升 ≤0.27 dB，**没有实质库外恢复**；AutoIR 的 abstain 是正确行为，但不能说已实现 open-world 恢复。**50 对固定子集已废弃**：该子集 LQ 均值 17.752 vs 全 495 的 17.100（容易约 0.65 dB），M_blind 在子集 17.917 vs 全量 17.307；同一 50 图在全量评估中数值一致（按官方 source index 映射），差异来自子集选择而非评估实现。
- 系统没有校准过的 unknown/OOD 检测器；只能报告 UNCERTAIN/POOR 与 fallback，不能声称 open-world 识别。E4 的结论应限定为“真实数据上可运行、能保守拒绝库外、但性能有限”。
- UHDM 是真正的库外（库内无 moiré 算子）：
  - **规则控制器**：5 对 support 上**没有任何类别达到 3/5 共识**，只能单对 fallback 到 `compression_jpeg:2`，verdict **POOR**（仿真 PSNR 18.81）。已训练 fallback specialist 并评估（495 对）：**17.373 / 0.6236 / 0.5068**，相对 M_blind 仅 +0.066 dB PSNR、SSIM/LPIPS 更差，没有实质恢复。
  - **AutoIR / Skill**：`pipeline: []`、`alternatives: []`、verdict **POOR**、`out_of_library: true`（高置信）。残差是全幅弯曲准周期彩色干涉图案；lag-1 空间自相关 0.71–0.93；所有库内候选都不优于 clean-vs-target 的 no-op（clean-vs-degraded PSNR 17.46–21.52；JPEG/blur/contrast 均无显著改善）；全局信号在各 pair 间互相矛盾。系统选择**不强行匹配库内算子**，这是正确的保守行为，但代价是无法为库外退化训练 specialist，只能回退到通用模型。
  - 当前系统没有校准过的 unknown 检测器；它输出 POOR/空 pipeline，而不是给出可量化的 OOD 概率。Qwen 噪声门在 UHDM 上未执行（Agent 无 API 工具）。
  - UHDM 基线（495 对全量，主基线为官方 DFPIR）：LQ 不恢复 **17.100**；M_blind **17.307 / 0.6387 / 0.5020**；**DFPIR 官方 5D 15.529 / 0.4716 / 0.5889**（−1.778 [−1.973,−1.590] vs M_blind）；DFPIR blinded 项目参考 **17.254 / 0.5847 / 0.5234**（−0.053 [−0.081,−0.025]）；规则 fallback specialist（JPEG:2）**17.373 / 0.6236 / 0.5068**（+0.066 [+0.043,+0.090] vs M_blind，但 SSIM/LPIPS 更差）。所有方法相对不恢复的提升 ≤0.27 dB，**没有实质恢复 moiré**；官方 DFPIR 还低于 M_blind。AutoIR 的空 pipeline/abstain 是合理的；系统没有库外恢复能力，也不应声称有。
- 真实噪声 vs 真实 moiré 的差异：SIDD 有 3/5 共识（噪声），系统能给出 UNCERTAIN 的库内近似；UHDM 无共识，系统应报告 POOR/回退而不是高置信预测。当前系统没有校准过的 unknown 检测器，不能声称 open-world 识别。
- **Rain100H 真实去雨（95 对）**：库内无 derain 算子；AutoIR/Skill 输出空 pipeline + POOR（out_of_library 高置信），恒等 **12.104 / 0.3640 / 0.5352**；M_blind **11.840**（−0.264 vs 恒等，5/95 胜）、DFPIR blinded **12.148**（+0.044，91/95）均无实质提升；含 derain 训练的 DFPIR official 5D **14.647 / 0.4811 / 0.4595**（+2.543，95/95）、PromptIR **15.470 / 0.5059 / 0.4446**（+3.366，95/95）、AirNet **14.516 / 0.5011 / 0.4534**（+2.412，95/95）。规则 specialist **16.392 / 0.4663 / 0.5521**（+4.288，86/95）PSNR 最高，但它是**全局光度捷径**而非去雨：ΔPSNR 与 degraded−clean 均值差的相关系数 **0.807**，输出均值 0.405 vs clean 0.444 / degraded 0.658，std 0.141 vs clean 0.216；LPIPS 反而比恒等差 0.017（SSIM +0.102）。因此 rain 结论只能支持“AutoIR 能保守拒绝库外；库内模型不迁移”，不能把规则的高 PSNR 当作去雨收益，也不能声称 open-world 去雨。
