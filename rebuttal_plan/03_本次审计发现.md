## 2026-10-27 补充：A0/E1 固定 LQ 的配对审计（7 个非确定性场景）

**发现**：A0（AutoIR）与 E1（rule）的 `lq_sha256` 在 8,400 个共同图像行中有 **2,450 行不一致**，正好是 **7 个场景 × 350 张**：`blind_0003/0005/0017/0018/0020/0022/0023`。其余 17/24 场景 hash 完全一致。

**原因**：GT 管线相同，但这 7 个场景包含 `noise_impulse`、`blur_glass` 等使用私有 RNG 的随机算子（skimage/numba），`random/np/torch` 的 hash seed 不能完全控制其 realization。因此同一 GT 参数在不同 run 中会采到**不同 LQ 样本**；这不是 GT 退化被换掉，而是同一分布的不同随机 realization。严格逐图配对必须使用同一份 LQ。

**修正**：
- 已用 `rebuttal_runs/E1E2_fixed_lq/` 为这 7 个场景 materialize 一份固定 LQ，AutoIR 与 rule 在同一份固定 LQ 上重评；`E1E2_fixed_lq_summary.json` 的 24 场景 macro/paired 与主指标差异 <0.001 dB（逐场景最大约 0.01 dB）。
- `rebuttal_plan/LLM_vs_rule_choices.md` 的 test 列已改为：17 个确定性场景用 A0/E1 主指标，7 个非确定性场景用 fixed-LQ；结论（LLM wins 16/7/1，平均 +0.697 dB）不变。
- `E1_oneshot_no_reflection.md` 的 one-shot 对照已用 `eval_oneshot_fixed_lq.py` 对 6 个共同 fixed 场景（不含 blind_0020）在同一份固定 LQ 上重评；23 场景结果微调为：rule 反思 +2.426 dB（18/23 胜）、LLM 反思 +1.279 dB（15/23 胜）、`AutoIR-full − rule-full = +0.636 dB [−2.44,3.49]`；方向不变。
- `blind_0020` 的 E1-oneshot R0 训练 NaN，按 **1/24 terminal failure** 单独报告；主表为 23 个有效场景 macro，不做 0 dB 插补/静默删除。E1-full 通过 R1 fallback 恢复（test 15.98），AutoIR-oneshot 15.78、AutoIR-full 18.09。Swin+SG 稳定重训只作可选 sensitivity，不进入主表。

**影响**：GT 参数/分布一致；未修正前 7 个场景的逐图 Δ 含额外 LQ 噪声，不能当作严格配对。宏观结论对 LQ realization 不敏感，但表格和 rebuttal 应使用 fixed-LQ 版本，并注明上述原因。
