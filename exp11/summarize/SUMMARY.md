# exp11 — 盲识别鲁棒性验证

## 目标

通过大规模交叉测试 (~1284 组)，量化盲识别错误对下游训练 PSNR 的损害程度，并建立数据驱动的误识别诊断规则。

## 实验设计

多层次验证矩阵：

| Phase | 内容 | 规模 |
|-------|------|:--:|
| Round 1 | 初始观察 | 8 组 |
| v2 (nearmiss) | 近邻退化混淆 | 19 组 |
| v3 (大规模交叉) | 盲验证矩阵 | 839 组 |
| phaseE | 严重度系统验证 | 308 组 |
| 盲验证 | 错误类型对照 | 26 组 (18 错 + 8 对照) |

## 核心结论

### 各类错误对 PSNR 的损害

| 错误类型 | 平均 PSNR 损失 |
|---------|:--:|
| **类型错误** (type) | ~17.5 dB |
| 严重度错误 (sev) | ~14.5 dB |
| 漏检全局退化 (missing) | ~12.9 dB |

### 关键发现

1. **退化类型识别错误代价最高**：把 blur_motion 识别成 blur_gaussian 比严重度偏差更致命
2. **全局退化极易被漏检**：brightness/contrast 对局部纹理指标不敏感
3. **content-independent 指标组合检测率达 94.4%**
4. **交叉测试学习到的诊断规则是概率性的**，非确定性硬规则

## 对后续实验的影响

- 为 exp13 的四层隔离协议提供了实验依据
- 确立了同图模式的必要性——跨图模式无法可靠识别全局退化
- 产出的诊断规则写入 `image-degradation-simulator` Skill
