# exp11：从数据和图像中学习误识别诊断规则

## 目标

利用 839 组交叉测试数据（数值 + 图像），学习"模型在错误退化上训练后，在正确退化上测试时"的失败模式规律，建立可操作的退化识别修正规则。

## 数据资产

| 类型 | 数量 | 内容 |
|------|:--:|------|
| 数值结果 | 839 组 | per-dataset PSNR + 诊断特征(edge/chroma/dir/hflf) |
| 预测图像 | 839 组 tar | 每组含 3 数据集 × 3 图(pred/gt/residual) = 7551 张 |
| 训练模型 | 60 个 | 覆盖 7 种架构 × 多种退化 |

## 学习计划（4 个 Phase）

### Phase A：数据画像 — 理解"正常"和"异常"的边界

**目标**：建立 baseline 分布，知道"正常修复"和"错误修复"在数值上长什么样。

**方法**：
1. 从 839 组中提取 self-test（训练退化=测试退化）作为"正常"基准
2. 分析 self-test 的诊断特征分布（均值/方差/分位数）
3. 定义异常阈值：偏离 self-test 分布 > 2σ 视为"诊断信号"

**产出**：
- 每个诊断特征的正常范围
- 异常检测的阈值表

### Phase B：误差类型聚类 — 同样的跨退化模式是否聚合？

**目标**：验证"同类型误识别 → 相似的失败特征"假说。

**方法**：
1. 按 train-test 退化对分组，计算每组的大 gap 比例
2. 提取大 gap 案例的诊断特征，做聚类分析
3. 如果有明显的聚类，标注每个聚类对应的误差类型

**产出**：
- 误差类型→特征签名的映射表
- 每个映射的置信度

### Phase C：图像特征提取 — 从残差图中学新特征

**目标**：超越简单的标量统计量，从图像中提取更丰富的诊断信号。

**方法**：
1. 从 839 组 tar 中提取代表性案例（每个误差类型 10 组）
2. 对残差图做更精细的分析：
   - **空间分布**：残差是均匀的还是集中在边缘/平坦区？
   - **颜色分布**：残差在 RGB 通道间是否不对称？
   - **纹理**：残差是否有方向性/周期性模式？
   - **频率**：残差的功率谱分布
3. 对比 skill 中已有的识别方法（指标纪律中的可信/不可信指标）
4. 设计新的图像级特征

**产出**：
- 新的诊断特征定义（可能比标量更有区分力）
- 图像→误差的视觉对照表

### Phase D：规则抽象 — 构建决策规则

**目标**：将前三个 Phase 的发现抽象为可操作的修正规则。

**方法**：
1. 合并数值特征（Phase A/B）和图像特征（Phase C）
2. 构建决策树或规则集
3. 在留出的 20% 数据上验证准确率
4. 与 REFLECTION_MECHANISM.md 中的初始规则对比

**产出**：
- 更新的诊断规则集
- 每条规则的准确率/召回率
- 修正 REFLECTION_MECHANISM.md

## 执行顺序

```
Phase A (2h) → Phase B (2h) → Phase C (3h) → Phase D (2h)
  基准建立      聚类验证      图像特征        规则抽象

总时间: ~9h (无需新训练, 纯数据分析)
```

## 关键假设

1. **H1**：大 gap 案例的残差图有明显的空间结构（非均匀噪声），可区分于小 gap
2. **H2**：不同误差类型（遗漏 vs 严重度 vs 顺序）对应不同的残差图纹理
3. **H3**：图像特征 + 标量特征组合 > 单独标量特征
4. **H4**：架构选择影响跨退化鲁棒性，但诊断特征的区分力是架构无关的

## 与 skill 的协同

- **Skill 擅长**：基于干净 GT 对比的退化识别（有监督）
- **本计划补充**：基于训练后模型表现的退化识别修正（自监督）
- **结合点**：Skill 做初始识别 → Phase 5 训练 → 本计划分析结果 → 修正识别 → 重训练
