# exp11 盲验证实验 — 反思机制有效性

## 实验设计

模拟盲识别误差：8 种 GT 退化 × 3 类误差（类型误判、严重度偏差、遗漏全局）= 24 组 + 8 组对照。

所有退化 ≥ 2 步（双退化或三退化）。

## 结果

### 总体

| 指标 | 数值 |
|------|:--:|
| 总实验 | 26（18 错误 + 8 对照） |
| 检出率 (>6dB gap) | **94% (17/18)** |
| 平均 gap (type) | 17.5 dB |
| 平均 gap (sev) | 14.5 dB |
| 平均 gap (missing) | 12.9 dB |

### 按误差类型

| 误差类型 | 检出/总数 | 检出率 | 平均 gap |
|------|:--:|:--:|:--:|
| **类型误判** | 7/7 | **100%** | 17.5 dB |
| **严重度偏差** | 6/7 | 86% | 14.5 dB |
| **遗漏全局** | 4/4 | **100%** | 12.9 dB |

## 结论

1. **反思机制有效**：94% 检出率，仅 1 例严重度偏差（BS sev-1, gap=5.4dB）低于 6dB 阈值
2. **类型误判最易检测**（100%），遗漏全局次之（100%），严重度偏差最难（86%）
3. **6dB 阈值合理**：捕获 94% 案例，false positive 可控
4. **接近严重度（±1）仍有 6.5-12.5 dB gap**：大部分可检测
5. **BS 退化是难点**：全局颜色变换（brightness_shift）的严重度差异小
